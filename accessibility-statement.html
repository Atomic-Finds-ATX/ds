Accessibility Statement

Last Updated: August 2026

Our Commitment

Atomic Finds ATX is committed to ensuring digital accessibility for people with disabilities. We are continuously improving the user experience for everyone, and applying the relevant accessibility standards including WCAG 2.1 Level AA parameters.

Accessibility Features on This Site

  • Keyboard Navigation: All interactive elements, links, inputs, and buttons are fully reachable via the tab key with a prominent 2px focus ring.
  • Screen Reader Support: Dynamic state attributes (aria-expanded and aria-hidden) are bound seamlessly on all expandable card widgets.
  • Reduced Motion Compliance: CSS transitions and scroll-reveal observers fully respect user 'prefers-reduced-motion' flags, disabling movement automatically.
  • Touch Targets: Interactive buttons and controls scale to a minimum of 44x44px target sizes on mobile resolutions to facilitate tap accuracy.
  • Bilingual Language Support: High-contrast translation hooks are natively embedded to enable client-side English/Spanish switching.
