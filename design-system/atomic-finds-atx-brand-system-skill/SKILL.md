# Atomic Finds ATX — Brand & Web Design System

Atomic Finds ATX curates 60s–70s vintage rattan/bamboo furniture in Austin. This skill reproduces its locked system across brand and web deliverables. **Furniture is always the hero.**

**Per-use variables:** the deliverable (IG post, product card, web section, email, signage); the piece(s) featured; aspect ratio/format.
**Locked constants:** palette, marks, type, pattern-usage rules, provenance-passport template, attribution rule, motion, voice — never change these.

Before generating, `read` the bound assets and pass the relevant ones as references for visual continuity. **Clean, ready-to-use files** (transparent where noted): `primary-logo.png`, `atomic-starburst-mark.png` (transparent), `sparkle-mark.png` (transparent), `icon-set.png` (transparent icon grid), `botanical-pattern.png`, `atomic-pattern.png`, `sparkle-pattern.png` (seamless tiles). **Reference anchors:** `solihiya-weave.jpg`, `passport-template.png`, `nacho-photo.jpg`, `brand-system-sheet.png` (overview). Drop the logo/marks/icons straight into layouts; use pattern tiles as backgrounds/frames.

## Palette, Type & Marks
Palette: Burnt Orange `#C8501E` · Avocado `#6B7A32` · Olive/Teal `#2E5D4E` · Warm Cream `#F3E6CE` (dominant base) · Mustard `#E0A526` · Pink `#E39AA8` (accent ONLY, sparing). Type: retro-groovy display for headings/piece names + clean sans for body; max 3 levels. The **atomic starburst is the ONE owned logo mark**; a recurring **sparkle/star** accent appears throughout. See `brand-system-sheet.png`.

## Pattern & UI Usage
ONE pattern per section, ONE role only, generous cream breathing room — never mix patterns or scales. Roles: (a) subtle tone-on-tone **hero background**; (b) thin **border/divider** for featured sections; (c) **card-as-frame** — pattern is the card background, product image sits on top with cream padding so the pattern frames it. Botanical may drop to delicate single-color **line-art**. The Solihiya weave is an **attributed texture** ("Solihiya · Philippines") — NEVER fused into the logo. See `botanical-pattern.png`, `solihiya-weave.jpg`.

## Layout
Showroom nav: Living Room · Kitchen + Dining · Office · Back Patio. Availability states: Available / Sold; link out to Facebook Marketplace. **Provenance-passport product template** (see `passport-template.png`): warm lived-in home photo, piece name + era in display type, atomic starburst, origin badge (named weave + plant, credited), one-line story, sparkle, small Nacho guide slot. Same template every time; only the regional detail swaps. Time Traveler's Record = collectible card per sold piece.

## Animation & Motion
Subtle and warm, never flashy: gentle fade/slide-in on scroll; soft hover lift + shadow on cards; a slow twinkle on the sparkle accent; pattern borders may softly "draw on." Honor reduced-motion. Motion supports the furniture, never distracts.

## Copy & Voice
Warm, curious, witty, colorful — never corporate or precious. Tagline: *Tiny Time Machines for Your Home.* Every piece is named (Orbit, Agnes, Miami) and sold like an adoption; provenance framing: "Found Across Time + Space," "This tiny time machine has found a new home." Nacho = the single mascot/guide (use real photos for now — see `nacho-photo.jpg`; illustrated mascot pending). Aliens = cameo Easter eggs only.

**Compliance check:** furniture hero · atomic starburst present · any weave/plant named + credited, never the logo · palette locked, pink accent-only, cream breathing room · one pattern per role · sparkle present · voice warm + witty.
